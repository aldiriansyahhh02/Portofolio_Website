Hotel Booking Demand Machine Learning

Predicting which hotel reservations will be canceled, so a hotel can plan rooms and reduce lost revenue.

Role and approach: Built a Random Forest model on 83,573 bookings from a hotel in Portugal. I tuned it with RandomizedSearchCV, chose a decision threshold of 0.37, and explained the results with SHAP.

  • Python
  • Pandas
  • Scikit-learn
  • SHAP
  • Jupyter Notebook
  • F2-score 0.814 and recall 88.9% on 16,715 test bookings
  • ROC AUC 0.888
  • Wrong-prediction cost down up to 72% (about EUR 1.59 million, upper-bound estimate)
